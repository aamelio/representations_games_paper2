# Manual GPT and Gemini arms — neutral-prompt rerun (round 1, task 3)

Paste-ready prompts for the two pending arms of the neutral-prompt rerun. Generated by
`../rerun_manual_prompts.py` from `../rerun_materials.json` (the frozen May texts);
identical to what the Claude arm received via `../rerun_runner.py`, so the three arms
differ only in the rating model. The full protocol is also in the appendix of
`post_meeting_tasks.tex`.

## Models

- **ChatGPT**: GPT-5.5 Thinking — the May round-1 model. If that exact version is no
  longer selectable, use the closest current reasoning-tier model and record the exact
  name; the comparison then confounds model and prompt, which the write-up must note.
- **Gemini**: Gemini 3 Pro (reasoning), same rule.

## Session protocol (6 sessions: 2 providers x 3 triplets)

1. Fresh conversation. No custom instructions, no memory/personalization (in ChatGPT,
   turn memory off or use a temporary chat), no web search or tools.
2. Paste `tripletN_prompt1.txt` (the whole file, one message). Wait for the reply.
3. Paste `prompt2.txt`. Wait.
4. Paste `prompt3.txt`. Wait.
5. Save the full conversation (all three replies, including the JSON blocks) to
   `../transcripts_rerun/` as `chatgpt_<version>_tripletN.txt` or
   `gemini_<version>_tripletN.txt` (May naming convention).
6. Never mention the game or story names, the paper, or the mapping below in a session.

One triplet per conversation; the three conversations per provider are independent.

## After the runs

Either hand the six transcripts to the analysis assistant for transcription and checks,
or append the ratings directly:

- `../rerun_recording.csv`: rows `model,triplet,game,story,rating` (canonical names via
  the mapping; model strings e.g. `gpt-5.5-thinking`, `gemini-3-pro`).
- `../rerun_splits.csv`: rows `model,triplet,game,story,points` from the Prompt-3 JSON
  (each game's two numbers must sum to 100).
