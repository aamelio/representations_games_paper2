# Consolidated final workflows from rounds 4--9

This directory replaces the former `round4`--`round9` working folders. It contains
only the material needed to reproduce the analyses currently reported in
`../../additional_similarity.tex`.

## Contents

- `vignette_similarity/`: final vignette source, construction documentation,
  blinded relative-similarity prompt and packets, retained agent ratings, analysis
  code, and the four figures used in Sections 1--2.
- `hp_similarity/`: HP source data, classification and similarity prompts,
  resumable blinded-rating records, final row-level data, plotting code, and the
  two figures used in Section 3.

The participant-level HP-weight regressions are a different exercise and live in
`../hps_weights/`.

The former `round1`, `round2`, and `round3` directories are intentionally unchanged.
