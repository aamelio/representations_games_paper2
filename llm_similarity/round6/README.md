# Round 6: joint-action vignette similarity

This folder contains the blinded inputs and the reproducible pipeline for rating the joint-action vignettes.

## Design

- Games: DG-KW, UG, and TG.
- Frames: Control, Market, Aid, and Bonus, giving 12 game-by-frame contexts.
- Aid and Bonus reproduce the experimental order: the story comes first, followed by the corresponding cleaned abstract-game instructions.
- Survey logistics such as implementation probabilities, screen-transition markers, and later elicitation-task language are omitted. Substantive payoff and decision information is retained.
- Every context is rated against all 30 vignettes. The model sees only neutral context and vignette identifiers.
- The prompt requests independent absolute similarity ratings from 0 to 100. It does not ask the ratings to sum to a fixed total.

## Files and workflow

1. `01_build_anonymized_inputs.py` parses `joint_action_vignettes_classified.txt` and the cleaned source contexts from round 2. It writes:
   - `anonymized_vignettes.csv` (30 neutral vignette IDs and texts);
   - `anonymized_contexts.csv` (12 neutral context IDs and texts);
   - `anonymization_map.json` (private mapping used only after scoring).

2. `02_rate_similarity.py` sends each neutral context and all 30 neutral vignettes to an API model. Each context-replicate is a fresh call, and vignette order is independently permuted. Example commands:

   ```text
   python 02_rate_similarity.py --dry-run
   python 02_rate_similarity.py --provider anthropic --model MODEL_ID --replicates 3
   ```

   The corresponding API key must be set in the environment. No API keys are read from or saved to repository files. Parsed scores are written atomically to `similarity_ratings.csv`; full prompts, responses, and label mappings are retained in `transcripts/`.

3. `03_analyze_similarity.py` normalizes each repetition first and then averages repetitions within model. The analysis pools are:
   - DG context: the 6 DG vignettes;
   - UG context: the combined 24 UG and TG vignettes;
   - TG context: the combined 24 UG and TG vignettes.

   The normalized individual vignette weights sum to one within every context. The class-total bars are sums of the individual vignette weights in the corresponding representation class and therefore also sum to one across classes. Run:

   ```text
   python 03_analyze_similarity.py
   ```

## Figure structure

- `control_similarity_distribution.png`: DG has M, S, and C classes. Each has two vignette bars (personal and anonymous-market) followed by its total. UG and TG have M-C, M-D, S-C, S-D, C-C, and C-D classes. Each has four vignette bars (UG-personal, UG-market, TG-personal, TG-market) followed by its total.
- `market_minus_control_similarity_differences.png`: Market minus Control for every individual vignette and class total, after separate normalization within condition.
- `aid_minus_bonus_similarity_differences.png`: Aid minus Bonus for every individual vignette and class total, after separate normalization within condition.

The individual difference bars sum to zero within each game comparison; the class-total difference bars also sum to zero.

The older `_within_game` PNG files are legacy outputs from the previous specification. They are not regenerated by the current script and are not referenced by `additional_similarity.tex`.

## In-task Codex exploratory ratings

`04_merge_codex_blind_ratings.py` validates and combines three blinded rating passes generated within a Codex task. The raters use only the anonymized inputs and neutral prompt; the private mapping is reattached after scores are fixed. These passes are repeated judgments from the same Codex model family, not independent external models or human raters. They provide an exploratory similarity estimate but not cross-model validation.

The full normalized data and plotted values are saved in `output/`. `weight_analysis_pool` is the weight used in the figures; `weight_all30` is retained as a diagnostic. The comparison data also retain unnormalized mean-rating differences.
